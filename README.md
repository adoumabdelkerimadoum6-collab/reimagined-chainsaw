# Portfolio Adoum

Portfolio statique pour Adoum, ingénieur en informatique appliquée, consultant et formateur.

## Structure

```text
portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
├── assets/
│   ├── images/
│   └── projects/
└── README.md
```

## Utilisation

Ouvrir `index.html` dans un navigateur ou utiliser l'extension Live Server de VS Code.

Le formulaire est actuellement une démonstration côté navigateur. Pour recevoir les messages, remplacer le comportement dans `js/main.js` par un endpoint Laravel, Formspree, Web3Forms ou une API maison.

Les liens GitHub, LinkedIn, l'adresse email et les informations de projets sont à personnaliser dans `index.html`.
